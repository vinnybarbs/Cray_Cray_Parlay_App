## What changed from v1

The VOC research invalidated v1's top two finalists for the dual-ICP test:

- **Trapline → weakened.** "Trap" is degen-tribal; sharps actively mock it ("im sick and tired of all this TRAP GAME STUFF" — r/SBR). The Trap *label* still works on a tile because product context disambiguates. The Trap as a *brand name* fails the equal-weight ICP rule.
- **DegenMath → weakened.** "Degen" is self-claimed by one ICP, pejorative when external. Alienates sharp-curious.
- **Fadeline → survives.** "Fade" is the only shared sharp+degen vocab in the trap-adjacent semantic space.

## Six archetypes driving Phase 2 (anchored in VOC findings)

| Archetype | Semantic territory | VOC evidence |
|---|---|---|
| **A — Revelation / "now you know"** | The user is on the inside, sees what the book sees | "Vegas knows" is the audience's villain frame |
| **B — Line direction / RLM / "the move"** | Sharp-coded under-claimed vocab | "reverse line movement," "steam moves," "the move" all surfaced repeatedly |
| **C — Plain statement-of-fact** | Outlier/Unabated/Public/Linear archetype | Trust register = "real," "actually," "makes sense," "no BS" |
| **D — Tool / instrument / not-guru** | Software-as-tool signaling, anti-tout | Audience antibodies trigger on guru-coded names |
| **E — Fade-family (survivor)** | Shared sharp+degen vocab | "Fade the public" canonical across both ICPs |
| **F — Audience's verbatim ("the move," "the read")** | Names that lift directly from audience speech | Trigger-event language ("what's the move?") |

## Notes

- Names like **Steam**, **Pulse**, **Tape**, **Drift**, **Settle** are common English words — `.com` will almost certainly be taken or expensive. TLD strategy shifts to `.bet`, `.app`, or `getX.com` patterns. Domain Brainstormer framework encourages this multi-TLD thinking explicitly.
- **Single-letter and 4-letter names** were tested informally and discarded — too crowded, no defensive moat.
- The **"The[Word]"** definite-article naming pattern (TheTell, TheRead, TheMove, TheLine) is a real recurring pattern in the surface — worth treating as a coherent family.
