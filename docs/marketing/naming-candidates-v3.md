## Constraint stack (locked from prior phases)

**Must avoid:** -picks, -capper, -tout, -pro, -lock, -guru, -expert, -elite, -VIP, -bet, fade-anything, trap-anything, generic [verb]+[noun] compounds, Oprah picks, podcast titles, active AEO platforms (Surfaced, Gauge, Outlier, Unabated, Rithmm, Stokastic — all taken).

**Must hit:** phonetic feel when spoken, distinctive in the wild, works for both ICPs without coding too hard for either.

## Archetype 1 — Invented math-coded single words

| Candidate | Rationale | Phonetic |

| Candidate | Rationale | Phonetic |

| **Aether** | Greek: the upper atmosphere, the invisible medium. Mythic. Crypto-adjacent (ether/Ethereum). | AY-thur · soft, mythic |
| **Logos** | Greek: word, reason, principle. Heavy but iconic. | LOH-goss · classical |
| **Ergo** | Latin: "therefore." Pure logic, four letters. | URR-go · punchy |
